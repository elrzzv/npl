# Задача 1.3 — рендер фрактала Мандельброта (Julia)

## Запись с демонстрацией
https://drive.google.com/file/d/1gOi2UQrNVnLYRDcpN96ZvdM3sWidcj8f/view?usp=drive_link

## Постановка задачи

Программа строит изображение 800×600 с пределом 1000 итераций на пиксель.
Последовательный и параллельный варианты сравниваются по времени и
побайтовому совпадению результатов. Параллельный вариант использует
`Threads.@threads`: потоки обрабатывают разные строки общего массива.
Изображение сохраняется в `mandelbrot.ppm` (бинарный PPM, P6).

## Требования

* Julia, доступная командой `julia` в терминале (проверено с 1.13.1).
* Дополнительные пакеты не требуются.

## Запуск

Из корня репозитория в PowerShell:

```powershell
cd ./1_task_3_julia
julia -t 4 Main.jl
```

`-t 4` задаёт четыре рабочих потока. Выводятся время обоих вариантов,
ускорение и `Buffers match: OK`. Файл создаётся в папке задания.
