# Задача 1.3 — рендер фрактала Мандельброта (Julia)

800×600, строки распределяются между потоками через `Threads.@threads`,
пиксели пишутся в общий массив без пересечения индексов. Печатается время
для 1 потока и для N потоков, картинка сохраняется в `mandelbrot.ppm`.

## Запуск

```powershell
cd C:\Users\89242\some_code\npl\1_task_3_julia
& 'C:\Users\89242\AppData\Local\julia\julia-1.13.1\bin\julia.exe' -t 4 Main.jl
```

`-t 4` — число потоков (без него используется 1).
