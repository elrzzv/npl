# Задача 1.1 — параллельная факторизация (Scala)

## Запись с демонстрацией
https://drive.google.com/file/d/1Tp5EKIgSufq-Q0SIjYLpmIoHKJmwFZLn/view?usp=drive_link

## Постановка задачи
Программа генерирует 1000 случайных чисел от 2 до 10¹² включительно и
раскладывает их на простые множители двумя способами:

* **последовательно** — в главном потоке, перебором делителей до √n;
* **параллельно** — пулом из 4 worker-потоков через
  `Executors.newFixedThreadPool(4)`. Каждое число — отдельная задача `Callable`,
  отправленная через `submit`; результаты собираются через `Future.get`
  в исходном порядке.

Выводятся по 2 примера разложения для каждого варианта, подтверждение
совпадения всех 1000 результатов, время обоих вариантов и ускорение.
Сообщения в консоли — на английском.
Генератор использует seed `42`, поэтому входные данные воспроизводимы.
Вывод в консоль не входит в замеры; параллельный замер включает создание
пула и сбор результатов. Ускорение зависит от компьютера и прогрева JVM:
один запуск — демонстрация, а не строгий бенчмарк.

## Требования

* JDK 17+; переменная `JAVA_HOME` указывает на каталог JDK.
* [sbt](https://www.scala-sbt.org/1.x/docs/Installing-sbt-on-Windows.html),
  доступный командой `sbt` в терминале.

Версии Scala и sbt заданы в `build.sbt` и `project/build.properties`.
При первой сборке sbt скачивает компилятор и зависимости, поэтому нужен
интернет. Отдельная установка Scala и расширения редактора не требуются.

## Запуск

Из корня репозитория в PowerShell:

```powershell
cd ./1_task_1_scala
sbt run
```

Строку `Total time` после завершения печатает сам sbt. В `.jvmopts`
задана английская локаль JVM, чтобы служебные сообщения также были
на английском и не зависели от отображения кириллицы в терминале.
