# Задача 1.2 — банковские переводы через STM (Haskell)

N счетов хранятся в `TVar`, 4 потока выполняют по 20 000 случайных переводов.
Каждый перевод — одна транзакция `atomically` с `readTVar`/`writeTVar`.
После завершения всех потоков проверяется, что сумма балансов не изменилась.

## Сборка и запуск

```powershell
C:\ghcup\bin\ghc.exe -O2 -o Main.exe Main.hs
.\Main.exe
```

или без компиляции:

```powershell
runghc Main.hs
```

## Окружение

* GHC 9.10.3 + cabal 3.16.1.0 (установлены через ghcup в `C:\ghcup`)
* Внешние пакеты не используются: только `base` и boot-библиотека `stm`
* Генератор случайных чисел — собственный LCG/xorshift (пакет `random` не нужен)
